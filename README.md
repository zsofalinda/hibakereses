# Hibakeresés – Webfejlesztés Gyakorlóprojekt

Ez a projekt négy szándékosan hibás kódot tartalmazó weboldalt foglal magába. A feladat a HTML, CSS és JavaScript fájlokban elrejtett szintaktikai és logikai hibák (pl. elgépelések, lezáratlan tagek, hibás függvények) felkutatása és javítása.

## A javítandó fájlok

* **`metumediadesign_hibas.html`**
  A METU Média Design szak bemutató oldala (HTML, CSS és JavaScript hibákkal).

* **`metropolitan_hibas.html`**
  A Budapesti Metropolitan Egyetem tájékoztató oldala (HTML, CSS és JavaScript hibákkal).

* **`kosar_hibas.html`**
  Egy egyszerű interaktív kosár számláló (főleg JavaScript és eseménykezelési hibákkal).

* **`google_hibas.html`**
  A Google kereső kezdőlapjának leegyszerűsített másolata (HTML, CSS és JavaScript hibákkal).

## Feladat
Nyisd meg a fájlokat egy kódszerkesztőben, keresd meg a hibákat, majd teszteld az eredményt a böngészőben!
